🔑 Has This Password Been Pwned?
🔐
How the online check protects you — k-anonymity. Your password is hashed with SHA-1 on this machine. Only the first 5 characters of that hash are sent to the free Pwned Passwords API, which returns ~800 candidate hashes. The final comparison happens here, offline. The server never sees your password, never sees the full hash, and cannot tell which of the 800 results you cared about. No API key is required.
🔒 Offline vs Online
Offline onlyWith k-anonymity
Network usedNone5 hash chars
API keyNoneNone
CostFreeFree
Corpus sizeYour imports + built-in list ~850 million real passwords
Password sentNeverNever
💡 If Your Password Was Found
  1. Change it everywhere you used it, starting with email and banking.
  2. Do not just add a number — cracking rules already try those variations.
  3. Switch to a unique passphrase per site, stored in a password manager.
  4. Turn on 2FA so a stolen password alone is not enough.
  5. Check your account's recent login activity for anything unfamiliar.
⚠️
A password being "not found" is reassuring but not proof of safety. It may simply not have appeared in a published dump yet.
