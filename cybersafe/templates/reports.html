📋 What a Case Report Contains
  1. Case metadata — number, type, priority, investigator, dates
  2. AI executive summary — a management-readable overview
  3. Evidence register — every item with acquisition hashes
  4. Chain of custody — the full audit trail
  5. Analyses performed — every scan with risk scores and verdicts
  6. Indicators of compromise — the complete IOC table
  7. Investigation timeline — chronological event list
  8. Integrity statement — hash verification results
  9. Methodology & limitations — a defensible statement of how it was done
🖨️ Producing a PDF
💡
Reports are generated as self-contained HTML with print styling built in. To make a PDF: open the HTML report, press Ctrl+P (Cmd+P on Mac), and choose Save as PDF. Page breaks and margins are already handled.
📦
HTML reports are fully self-contained — the CSS is embedded, so the file can be emailed or archived and it will still render identically anywhere, with no internet access.
⚖️
These reports are produced by an educational platform. For court proceedings, findings should be reproduced and corroborated by a certified forensic examiner using validated tooling.
